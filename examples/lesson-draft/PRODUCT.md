# Product facts — fictional example

Lesson Draft accepts pasted lesson notes and generates a worksheet draft. Teachers edit questions and accepted answers before assignment. Students receive the assigned worksheet through a link. No claim about time saved or learning outcomes has been measured.

The trial includes five worksheet drafts, requires account creation, and does not require a payment card. “Start trial” opens the account creation form. There is no public instant demo.

The UI calls the teacher container a “project”; backend storage uses `organization`. Saving a draft persists it. An upload being accepted does not mean generation finished. A generic save failure cannot identify a network cause and does not alert a staffed support team. The interface provides a “Try again” action for failed saves. Local draft recovery has not been verified.

“Archive project” hides it from the active list; the project can be restored from Archived projects. Permanent deletion is not supported in this scenario.

These are supplied fictional facts for the example, not claims about a live product. Last reviewed October 2, 2026.
